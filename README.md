> After 15 years building mostly things I couldn't share, now I'm building something I can share. Current focus:
> making AI + human work more intuitive — so anyone can get the leverage.

I coded my first website in Notepad. Now I orchestrate agents.

In between: medical software in Sweden at 18, developer communities across 14 countries at Microsoft, election infrastructure that couldn't fail on voting day, a core banking API reverse-engineered from zero docs, zero-downtime launches at Amazon.

Most of that work was invisible. Now I'm building in public.

## Projects

_Closed-source, but lots of learnings to share — details on the blog._

- 🔊 **Real-time voice AI pipeline** — containerized app for autonomous WhatsApp phone calls using STT, VAD, LLM, and TTS on AWS EC2
- 🎙️ **Intuitiva** — containerized app for live AI assistance on real phone calls using SIP, VoIP, and WhatsApp on Fly.io
- 🤖 **Google Meet bot** — containerized app for real-time LLM interaction with meeting participants using STT/TTS and Google Meet
- 🔌 **IoT fleet management** — platform for managing crypto nodes and data hotspot fleets on Raspberry Pi devices

- 👥 **Volunteer onboarding system** (Zynn.io) — platform for organizing thousands of election volunteers across hundreds of voting centers and managing operations in real time
- 🏦 **Core banking REST API** (Banco G&T) — custom REST API wrapper built by reverse-engineering an undocumented internal core banking system; cut delivery from 1 year to 2 months
- 📦 **Internal CRM & automation** (Vana) — platform built in two versions: V1 in Google Sheets and Google Scripts, V2 in Retool; cut payback validation from 24h to seconds
- 📊 **Donations tracker** — distributed CRM for managing over $2M in donations across a hierarchy of sellers, coordinators, and admins using Google Sheets and Google Scripts
- 🦷 **Patient management software** (DentalEye, Sweden) — new desktop app and modules built from scratch for osteoporosis detection used by Swedish doctors

- 🎤 **Interview copilot** — Chrome extension for real-time LLM-generated answers during live calls
- 🗳️ **Ballot scanning app** (Zynn.io) — mobile app for scanning and transmitting handwritten paper ballot results from the field using PhoneGap and OpenCV
- 📍 **GPS tracking app** (Zynn.io) — mobile app for cross-platform field operations using Xamarin and C# on Windows Phone and Android

- 🌐 **Global trade compliance** (Amazon) — backend service for importation and compliance across Amazon's international markets using Java
- 🤖 **On-call automation** (Amazon) — automation scripts for replacing manual runbooks using Jupyter Notebooks
- 🔍 **Fraud detection** (Vana) — detection service for cross-matching hundreds of bank micro-transactions to prevent fraud using Python on AWS
- 📱 **Windows Phone cross-sale playbook** (Nokia) — sales playbook for Windows Phone adoption with technical demos across 8 countries
